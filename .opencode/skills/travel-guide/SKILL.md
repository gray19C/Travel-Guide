# 旅游攻略写作规范

## 质量自检清单

每份攻略产出前逐条核对：

- [ ] 价格、营业时间、开放状态、交通班次、预约要求是否已核实并标注来源
- [ ] 每天的时间线是否排得开，有没有把相距远的景点塞进同一时段
- [ ] 交通耗时是否真实可查，而非估计值
- [ ] 有没有闭馆日 / 周一闭馆 / 节假日休馆冲突
- [ ] 预算是否覆盖全程（交通、门票、住宿、餐饮），不只是门票
- [ ] 是否标注了需要提前预约的项目及其截止时间
- [ ] 是否给出了天气相关的提醒和备用方案
- [ ] 是否有查不到因而未核实的内容，且已明确标注

## 行程可执行性检查

- 同一时段不要排两个地理上相距远的景点
- 热门景点放在上午，避开人流高峰
- 每天留出至少 1 小时缓冲应对延误
- 单日步行 / 移动总量要考虑体力上限
- 闭馆日、周一闭馆、节假日休馆要显式提醒
- 涉及跨境或需要证件的行程，提示证件与签证要求

## 目的地知识库

按目的地分节追加可靠背景信息。每个目的地建议覆盖：

- **最佳季节**：不同月份的优势与劣势、气候特点
- **必去清单**：核心景点，附建议停留时长
- **避坑提醒**：常见骗局、物价陷阱、体验较差的选项
- **小众替代**：热门景点拥挤时的替代方案
- **交通网络**：机场到市区、市内交通方式、跨境交通
- **当地特色**：饮食、节庆、必须体验的项目

## 参考资料可信度优先级

1. 官方网站 / 官方公告
2. 官方公众号、官方票务平台
3. 主流旅游平台的用户数据
4. 个人游记与社交媒体（仅作参考，需交叉验证）

## 攻略文件约定

攻略写入 `guides/<目的地>-<天数>天-<出发日期>.md`，例如 `guides/京都-5天-20261001.md`。

正文模板见项目根目录的 AGENTS.md。
